# Portfolio · Antoine HOUNDONOUGBO

Site portfolio bilingue (FR/EN) déployé sur GitHub Pages :
https://antoine-houndonougbo.github.io/

## Structure du dépôt
- `index.html` : Accueil, résumé du profil et indicateurs clés
- `a-propos.html`, `competences.html`, `experience.html` : Parcours, compétences techniques et expériences professionnelles
- `realisations.html` : Résultats d'analyses, figures STROBE et coffre des projets à accès par code (AES-GCM)
- `statistiques.html`, `galerie.html` : Démarche biostatistique et galerie de 31 visualisations R/ggplot2 et QGIS
- `en-action.html` : Photographies de laboratoire, de terrain et de formation (avec emplacement disponible `assets/photos/evenements-01.jpg`)
- `publications.html`, `certifications.html`, `contact.html` : Publications scientifiques, 8 badges IBM/Credly et coordonnées
- `cv/` : CV téléchargeables en français (`CV_Antoine_HOUNDONOUGBO_FR.pdf`) et en anglais (`CV_Antoine_HOUNDONOUGBO_EN.pdf`)

## Ajout d'une photo dans l'emplacement libre
Pour remplacer l'emplacement libre de la page `en-action.html` par une nouvelle photo :
1. Nommer le fichier `evenements-01.jpg`.
2. Le déposer dans le dossier `assets/photos/`.
3. La page l'affichera automatiquement à l'ouverture.
